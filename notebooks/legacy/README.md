# Archived notebook builder

`build_v33.py` records the historical migration from v3.2 to v3.3. It is preserved
for reference and is not a supported build/release entry point from this location.
The v3.2 and v3.3 notebooks retain their original code in `notebooks/`.

Maintain v3.4 directly and use `scripts/check_notebook.py` to check it or refresh
the embedded setup guide. No historical notebook is required to run v3.4.
